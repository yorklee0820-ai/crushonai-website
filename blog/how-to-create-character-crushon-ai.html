How to create a character on CrushOn AI

A CrushOn AI character is only as good as its card. Fifteen minutes of writing is the difference between a character that holds its voice for a hundred messages and one that collapses into generic chatbot prose by message twenty. 18+

The short answer

Sign in, open the character creator, and fill in name, personality, opening scenario, example dialogue and voice. The one thing almost everyone skips is example dialogue — and it is the field that matters most. Write at least five short exchanges that demonstrate exactly how the character speaks. Then chat for twenty messages, note where the character drifted, and revise the card.

What each field actually does

Name and avatar

Cosmetic, but not irrelevant: a distinctive name helps the model keep the character separate from generic archetypes it has seen in training. Avoid names that are effectively category labels.

Personality

Write in specifics and contradictions, not adjectives. “Deflects with humour when cornered, then over-shares at 2am” gives the model behaviour to perform. “Funny, shy, flirty” gives it nothing to work with and will dissolve within a session.

Scenario / opening situation

This is your highest-leverage field after dialogue. Drop the character into a concrete situation with stakes — where they are, what they want, what is in their way. A vague premise forces the model to invent context, and invented context is generic by default.

Example dialogue

Five or more exchanges, ideally covering different emotional registers: how they greet you, how they argue, how they react when caught out. This teaches tone, sentence length, vocabulary and pacing far more effectively than any description. Cards with strong example dialogue measurably outperform description-only cards.

Speaking style

Sentence length, formality, verbal tics, and — usefully — what the character never says. Negative constraints work surprisingly well here.

Voice

Choose from 40+ presets across nine languages, tagged by personality and accent. Higher tiers allow custom voice design. You can change it later, and mid-conversation on supported plans.

Step-by-step

  1. Start from a template or blank. Templates for common archetypes are a decent scaffold — customise heavily rather than shipping them as-is.
  2. Write the personality last. Draft the scenario and dialogue first, then summarise the personality from what you wrote. The summary will be more specific.
  3. Add five-plus example exchanges. Non-negotiable if you care about voice consistency.
  4. Keep it private first. Iterate privately, publish once the character behaves.
  5. Test with twenty messages. Read where it drifted and patch those exact fields.
  6. Test on a second model. If a character only works on one model, it is under-specified.

Common mistake: writing a long backstory and no dialogue. Backstory gives the model facts; dialogue gives it a voice. If you only write one, write dialogue.

Why characters drift (and how to fix it)

Drift almost always traces back to one of three causes: the card is defined by adjectives rather than behaviour; the opening scenario has no stakes so the model defaults to pleasantries; or the conversation has run past the context window, in which case the fix is a higher memory tier rather than a better card. Our memory guide covers the third case.

FAQ

How long does it take?

15–30 minutes for a solid card. Distinctive characters usually need several revision rounds.

Why does my character drift out of voice?

Usually adjective-only definitions. Add five or more example exchanges showing tone and pacing.

Can I keep a character private?

Yes, and you can change visibility later — private is the better default while iterating.

Can I edit a character after publishing?

Yes. Editing affects new conversations; existing chats keep their earlier context.

Do I need a paid plan to create characters?

No. Creation is available on the free tier, though free accounts have a limit on profile cards.
